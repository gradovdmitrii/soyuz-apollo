# Adapters

## Purpose

Turn boundaries B1, B3, B4, B5, and B6 into client permission settings, from one source: `.agents/policy.toml`. Adapters reinforce the boundaries; each client enforces its settings in its own way (limits L3).

## MUST

- A1. `python sa.py` never reads or changes global client configuration (`~/.claude`, `~/.codex`, `~/.hermes`, `~/.gemini`). The owner applies the fragments below by hand.
- A2. Never edit a generated adapter. `.agents/policy.toml` is part of the core and changes with a new release; then run `python sa.py sync`.
- A3. Adapters and fragments are `claimed` unless `.agents/docs/compatibility.md` records a trial; take statuses from that file and record new results there.
- A4. `sync` overwrites an adapter only when it carries the S-A marker (STANDARD S13). An owner-written file stays unchanged; `sync` and `doctor` report it.
- A5. If a client refuses a `python sa.py` command under these rules, do not work around it; tell the owner the command and the reason.

Generated by `python sa.py sync` in the installation root:

| File | Client | Covers | Marker |
|---|---|---|---|
| `.claude/settings.json` | Claude Code | B1, B3 (`Read` deny), B6 (`Edit` deny), B4 (`Bash` deny), B5 (`Bash` and `PowerShell` ask) | field `env.SA_ADAPTER` |
| `.codex/config.toml` | Codex | B1, B3 (`deny`), B6 (`read` only) in the permission profile `s-a` over `:workspace` | first line `# GENERATED ...` |
| `.codex/rules/s-a.rules` | Codex | B4 (`forbidden`), B5 (`prompt`) as `prefix_rule` | first line `# GENERATED ...` |

- `<archive>` is `paths.archive` from `.agents/config/instance.toml`; when empty, `<installation>-archive` next to the installation. It must be absolute and outside the installation.
- Path forms: Claude Code `//c/soyuz-apollo-november-archive`; Codex `C:/soyuz-apollo-november-archive` (unverified).
- `.claude/settings.json` also sets `SA_AGENT = claude-code`, so `python sa.py commit` signs `Agent: claude-code`.

## STEPS

Owner steps, once per installation:

1. Codex: mark the installation folder as trusted in Codex. Codex loads `.codex/` only for trusted projects; `sa` cannot do this for you.
2. Claude Code: put personal settings into `.claude/settings.local.json`; Claude Code merges it with the generated file.
3. Codex: keep personal settings in your user Codex config, not in `.codex/config.toml`.
4. Hermes Agent, Antigravity, DeepSeek Harness: apply the fragment for your client from EXAMPLES; replace `<archive>` with your archive path.

## EXAMPLES

Hermes Agent, in `~/.hermes/config.yaml`. The deny list applies even in YOLO mode. Hermes has no general read deny for a folder; the archive is protected only by living outside the installation (B1).

```yaml
approvals:
  mode: manual
  deny:
    - "git push*"
    - "git commit*"
    - "git clean*"
    - "git reset --hard*"
    - "git rebase*"
```

Antigravity, Deny and Ask lists in the app settings or in `~/.gemini/antigravity-cli/settings.json`. On Windows, commands that cannot be split into words need an exact match or a `regex:` entry.

```text
Deny:
read_file(<archive>)
write_file(.agents/)
command(git push)
command(git commit)
command(git clean)
command(git reset --hard)
command(git rebase)

Ask:
command(rm -rf)
command(Remove-Item -Recurse)
```

DeepSeek Harness: choose the preset `workspace-write` with approvals `ask`. It has no official command or path deny; third-party permission plugins are not used in 0.2. B1-B9 stay conventions there, with `python sa.py doctor` and Git for recovery.

## IF UNSURE

- A client ignores an adapter or a fragment: treat the boundaries as conventions for that client and report it to the owner.
- `sync` or `doctor` reports `ADAPTER-OWNER`: leave the file; the owner moves its settings as the message says and deletes it.

## REFERENCES

- `.agents/policy.toml` - the policy source. If missing: `sync` refuses; restore it from the release.
- `.agents/docs/compatibility.md` - what each client is known to enforce. If missing: treat every adapter as untested.
- `.agents/docs/limits.md` - what the framework does not guarantee. If missing: assume rules are conventions only.
