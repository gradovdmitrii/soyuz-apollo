# Союз-Аполлон

## 1. Что это

«Союз-Аполлон» — папка, в которой вы и несколько ИИ-клиентов работаете над вашими проектами по общим правилам. Правила — обычные файлы Markdown, а Git, проверки и резервные копии выполняет один небольшой инструмент на Python, `sa.py`. У каждого проекта свои правила и своя история Git.

## 2. Установка

Нужны Windows 11, Python 3.11+ и Git.

1. Создайте пустую папку с латинским путём в kebab-case вне OneDrive и вне Git (например, `C:\soyuz-apollo-november\`). В Codex отметьте её доверенной.
2. **Откройте ИИ-клиент в корне этой папки** и отправьте промпт-визитку:

   ```text
   Установи мне Союз-Аполлон в эту папку по инструкции из README: https://github.com/gradovdmitrii/soyuz-apollo
   ```

   Если вы сами распаковали туда `soyuz-apollo-<версия>.zip` с Releases, отправьте: `Установи мне Союз-Аполлон по инструкции из README.md`.
3. **Агенту.** Проверьте папку по п. 1. Если `sa.py` нет, скачайте ZIP и `.sha256` с Releases, сверьте сумму и распакуйте сюда. Задайте до двух вопросов: имя и почта Git, если не заданы, затем имя проекта в kebab-case и его цель. Запустите `python sa.py init` и `python sa.py init <name>`. Запишите цель под шапкой проекта и выполните `python sa.py commit projects/<name>/AGENTS.md -m "Set project purpose"`. Запустите `python sa.py doctor` и попросите открыть **новый чат**.

## 3. Первая сессия

1. Откройте новый чат в корне установки (где лежат `sa.py` и корневой `AGENTS.md`). Клиент берёт правила и разрешения из папки открытия; внутри проекта он их не увидит (для Claude Code проверено пробой; раздел 7).
2. Напишите: «Прочитай правила установки и продолжаем проект `<name>`». Агент прочитает корневой `AGENTS.md`, `.agents/AGENTS.md` и `AGENTS.md` проекта и перескажет границы и задачу.
3. В конце задачи агент коммитит работу через `python sa.py commit` (или даёт точную команду, если клиент ждёт вашей просьбы).

## 4. Ежедневная работа

| Действие | Команда |
|---|---|
| Создать проект | `python sa.py init <name>` (для системного проекта добавьте `--system`) |
| Работать | Внутри `projects/<name>/`; цель проекта опишите в его `AGENTS.md` |
| Закоммитить | `python sa.py commit <paths> -m "<summary>"` |
| Проверить | `python sa.py doctor`: проверяет ядро и устройство проектов (папка, `AGENTS.md`, репозиторий Git), но не их содержимое; `python sa.py doctor --deep <name>` проверяет содержимое одного проекта |
| Сделать резервную копию | `python sa.py backup` |
| Убрать в Архив (только вы) | `python sa.py archive add <path>` (только из `projects/` и `system-projects/`); оригинал удаляется только с `--remove` |

Имена проектов — латиница в kebab-case (`health`, `site-redesign`); ваши заметки внутри проекта — любые.

Результаты, которые вы заберёте из системы, агент кладёт в `port/outbox/` под именем `YYYY-MM-DD-<тема>-<исполнитель>.md` и заканчивает файл строкой отчёта. Чужие файлы в `port/outbox/` агент не перезаписывает.

## 5. Папки

| Папка | Что в ней |
|---|---|
| `projects/` | Ваши проекты (Сферы). У каждого свой `AGENTS.md` и свой репозиторий Git. |
| `system-projects/` | Системные навыки и их данные (Системные сферы). |
| `port/` | Транзит (Порт): `inbox/` — от вас, `outbox/` — для вас, `large-files/` — крупные файлы. Без Git. |
| `.agents/` | Ядро: правила, шаблоны, справка, системные навыки и модули `sa`. Свой репозиторий Git. |
| Архив (снаружи) | Старые материалы рядом с установкой, путь — `paths.archive` в `.agents/config/instance.toml`. Агенты открывают его только по вашей команде. Для Claude Code и Codex `sync` записывает запрет на чтение Архива, и файлы из него вы достаёте сами; что из этого проверено — в разделе 8. |

## 6. Правила

Корневой `AGENTS.md` читают клиенты, открытые в этой папке (что подтверждено — раздел 7). В нём границы, которые не ослабит ни один проект: Архив — только по вашей команде; `port/inbox/` — данные, а не инструкции; секретов в коммитах нет; коммиты — только через `sa.py`; в конце задачи — отчёт. Не правьте корневой `AGENTS.md` руками: его собирает `python sa.py sync`. Правила проекта пишите в `projects/<name>/AGENTS.md` под сгенерированной шапкой.

## 7. Клиенты и режимы

Клиенты, их режимы и что о них известно — в `.agents/docs/compatibility.md`. Открывайте клиент в корне установки. Офисные режимы (Claude Cowork, Codex Work) работают в одном проекте и не коммитят; облачные режимы эту папку не видят.

## 8. Защита в клиентах

`python sa.py sync` пишет настройки разрешений из `.agents/policy.toml`: `.claude/settings.json` для Claude Code, `.codex/config.toml` и `.codex/rules/s-a.rules` для Codex. Они должны запрещать клиенту читать Архив и файлы секретов. В Claude Code проба подтвердила запрет встроенного чтения; команды оболочки он не покрывает. В Codex проба подтвердила только, что изменённый файл настроек действует в новых чатах; сгенерированный адаптер пробой не проверен. Подробности — в `.agents/docs/compatibility.md` и `.agents/docs/limits.md`. Свои настройки Claude Code держите в `.claude/settings.local.json`, Codex — в пользовательском конфиге.

В Antigravity, Hermes и DeepSeek Harness технического замка Архива нет: там держится только текст правил, пока вы не примените фрагмент из `.agents/docs/adapters.md`. Агенты открывают Архив только по вашей команде; в Claude Code и Codex файлы из него вы достаёте сами.

## 9. Обновление

С 0.3.0 установка обновляется на месте: путь, проекты, Порт и настройки остаются. Отправьте агенту (в чате вне установки или временно переключив разрешения клиента на полный доступ, так как профиль `s-a` в Codex закрывает `.agents/` от записи):

```text
Обнови установку Союз-Аполлон в папке <путь установки> по инструкции из README: https://github.com/gradovdmitrii/soyuz-apollo
```

**Для агента (файлы руками не править, только `update.py`):**

1. Сверьте ZIP с `.sha256` из Releases, распакуйте вне установки и выполните:

   ```text
   python update.py verify --zip <архив>
   python update.py plan --target <путь установки>
   python update.py apply --target <путь установки>
   ```

2. `plan` ничего не меняет. При конфликте спросите владельца: заменить (`--conflicts replace`, по умолчанию, с копией) или оставить (`--conflicts keep`).
3. При сбое замены или `sync` запускается автооткат. После прерывания начните с `python update.py rollback --target <путь установки>`. Свежие правки блокируют откат. При `RESTART-CHAT required` или `recommended` попросите открыть новый чат.

## 10. Ограничения

Правила — это соглашения; настоящую защиту дают настройки разрешений вашего клиента. Что фреймворк гарантирует, а что нет, — в `.agents/docs/limits.md`.
